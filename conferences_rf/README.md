# Конференции.РФ

Веб-приложение по методическому пособию: HTML5, CSS3, JavaScript, Flask, PostgreSQL.

## Возможности
- Главная страница с автоматическим слайдером и каталогом помещений.
- Регистрация с проверкой полей на клиенте и сервере, вход и выход.
- Личный кабинет, создание и удаление новых заявок, отзывы по завершённым заявкам.
- Панель администратора: фильтр, смена статусов и удаление заявок.
- Пароли хранятся в виде хешей; доступ к страницам ограничен ролями.

## Запуск в ROSA Linux
1. Установите Python 3, PostgreSQL и Git.
2. Создайте роль и базу:
   ```sql
   CREATE USER conf_user WITH PASSWORD 'conf_pass';
   CREATE DATABASE conferences OWNER conf_user;
   ```
3. Выполните схему:
   ```bash
   psql -h localhost -U conf_user -d conferences -f schema.sql
   ```
4. Создайте окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
5. Создайте администратора и запустите сайт:
   ```bash
   python create_admin.py
   flask --app app run --debug
   ```
6. Откройте http://127.0.0.1:5000

## Важно
Параметры PostgreSQL заданы в `config.py` в соответствии с учебным примером. Перед реальным развёртыванием измените `SECRET_KEY` и пароль БД. Bootstrap в этом комплекте не включён локально: интерфейс стилизован собственным адаптивным CSS и не требует интернета.
